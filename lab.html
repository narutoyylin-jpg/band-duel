雙人房間規則

各有 12 點，第 1 回合設計自己的能帶、不計分；第 2～5 回合可修改自身、干擾對方或保留點數。自身每移動 0.02 eV 花 1 點，干擾花 2 點；設計最多 0.08 eV，攻防最多 0.04 eV，位差限制 ±0.16 eV。

Shuffle 派發指定位置的 Type I／Type II 任務。Type 與目標位置達標得 1 分，兩種載子比例都達 90% 再加 1 分。雙方同 Type 時，先確認 Type 符合，再以各自目標中電子、電洞比例較低的一項比較，較高者得分；相同則不加分。

每支手機只收到自己的任務、動作與已揭曉結果。雙方都鎖定才更新能帶；下一回合也需要雙方按「準備」。房間保留兩小時，同一分頁重新整理可回到原座位。

怎麼玩？計分與秘密出招規則

共 5 回合。第 1 回合是秘密設計，不計分；第 2～5 回合揭曉後計分，最後比較累積分數，相同則平手。

不同 Type：符合自己的 Type 得 1 分，電子與電洞在目標側都至少達 90%，再加 1 分。相同 Type：先確認排列符合共同的 Type，再比較雙方的目標比例；每人取「電子比例、電洞比例」較低的一項，較高者得 1 分，達 90% 再加 1 分。完全相同則雙方不加分；Type 不符也不加分。例如電子 95%、電洞 75%，比較值就是 75%。

導帶看電子，價帶看電洞。Shuffle 從四個目標隨機派發：Type I 聚在 A／B，或 Type II 電子在 A、電洞在 B／方向相反。雙方收到不同的收集目標，可以是相同或不同 Type。

每人共 12 點。1 點可調整自身位差 0.02 eV；干擾對方每 0.02 eV 要花 2 點。第一回合可設計 0.02～0.08 eV，之後每次最多改動 0.04 eV，也能選擇保留點數。位差限制為 ±0.16 eV；同一能帶上的動作同時相加，相消仍各自扣點。

電腦在你選擇前，根據上一回合公開能帶、雙方點數和可能動作鎖定計畫；不讀取你的秘密選項。公開上一回合的能帶與比例，隱藏當回合的新動作。自己的滑桿會顯示秘密計畫與試算；鎖定後才更新公開結果。

點數是遊戲規則，不代表實際功耗。這是室溫理想能帶模型；調整代表假想材料組合，非實際材料即時改變能帶。

Type I

包覆型 · Straddling alignment

目前的排列
能帶怎麼排？
一種材料的能隙，被另一種材料的能隙包住。圖中 B 的導帶較低、價帶較高；以 B − A 定義位差時，兩個位差的符號相反。
載子在哪裡？
電子找低導帶、電洞找高價帶，因此都偏向能隙較小的材料；也能把排列反轉，讓兩者都偏向 A。
有什麼影響與用途？
有利於電子與電洞的空間重疊，增加相遇、復合的機會。復合是導帶電子填回價帶空位的過程；在適合的材料中，能量可化為光。常見於 LED、半導體雷射的載子侷限結構。

Type I 有利於載子聚在一起；實際發光效率仍取決於直接／間接能隙、缺陷和注入條件。完整侷限結構通常需要兩側的障壁。

Type II

交錯型 · Staggered alignment

目前的排列
能帶怎麼排？
兩種材料的能隙交錯。圖中 B 的導帶和價帶都較低；以 B − A 定義位差時，兩個位差的符號相同。
載子在哪裡？
最低導帶在 B，最高價帶在 A，所以電子與電洞偏向介面的不同側。兩個位差都反轉，就交換它們偏向的材料。
有什麼影響與用途？
空間分離通常會減少電子與電洞的重疊、延緩部分復合過程，有利於把光生載子分開收集。可用於光偵測、光伏與電荷轉移結構；也能形成跨介面的電子－電洞對。

Type II 仍可能發生跨介面復合與發光。分離也不保證高效率：界面缺陷、載子傳輸和電極收集能力都會影響結果。

分類告訴你「偏向同側或不同側」；位差的大小決定偏好有多強。例如 0.01 eV 小於室溫熱能，雖然仍能分類為 Type I 或 Type II，載子可能只有約六成在有利的一側。

怎麼讀這張圖？

橫軸是位置，左邊是材料 A、右邊是材料 B；縱軸往上代表能量越高。藍線是導帶底，橘線是價帶頂，兩條線之間是能隙。介面上的高度差，就是能帶位差。

為什麼電洞往較高的價帶？

這張圖畫的是電子的能量。電洞是價帶中缺少電子的空位，它的能量趨勢和價帶電子相反，因此電洞偏向價帶頂較高的一側。

查看模型假設與分布公式

這是用來理解位差的理想模型：溫度固定為 300 K，兩側體積相同，有效態密度相同，載子稀少且服從波茲曼近似。對每一類載子，兩側具有相同的（準）費米能階，因此可以比較介面兩側的相對濃度。

nB / nA = exp(−ΔEC / kBT)pB / pA = exp(+ΔEV / kBT)

室溫下 kBT ≈ 0.0259 eV。材料 A 的參考能隙固定為 1.60 eV；材料 B 的能隙為 1.60 + ΔEC − ΔEV（eV）。導帶與價帶位差可分別調整，代表探索不同的假想材料組合。

比例分別以電子總量、電洞總量歸一化；它們不代表絕對濃度或兩種載子的總量相等。這裡省略能帶彎曲、摻雜、界面電荷、自洽電場和量子效應；單一介面呈現載子對一側的偏好，完整量子井還需要另一側的障壁。滑桿範圍涵蓋 Type I 與 Type II，不包含破裂能隙的 Type III。

對戰的比例來自理想模型，不代表實際元件效率。點數只是遊戲限制。電腦對戰重新整理就會重設；雙人房間在同一瀏覽分頁可重新連線，房間兩小時後到期。下載版可自由探索與對戰電腦，雙人房間需開啟線上網站。
