# 安裝 Band Duel / Install Band Duel

[繁體中文引導](https://band-duel.bandduel-game.workers.dev/play?install=1&lang=cn) · [English guide](https://band-duel.bandduel-game.workers.dev/play?install=1&lang=en)

![Band Duel installation QR code](band-duel-install-qr.png)

## 繁體中文

掃描 QR Code 開啟安裝引導；視窗內可切換繁體中文或 English。

- **Android Chrome**：看到「安裝 App」時，點選後依瀏覽器確認。若沒有按鈕，開啟 Chrome 的 ⋮ 選單，選「新增至主畫面／安裝應用程式」，再確認安裝。
- **iPhone／iPad Safari**：開啟「分享」（方框向上箭頭），選「加入主畫面」，再按「加入」。若出現「以網頁 App 開啟」，保持開啟。
- **App 內建瀏覽器**：複製遊戲網址，改用 Chrome 或 Safari 開啟，再依引導操作。

安裝後可從桌面的 Band Duel 圖示開啟遊戲。遊戲與登入需要網路。

## English

Scan the QR code to open the guide. Choose English or 繁體中文 inside the guide.

- **Android Chrome:** Tap **Install app** when available and confirm in your browser. Otherwise, open Chrome’s ⋮ menu, choose **Add to home screen / Install app**, then confirm.
- **iPhone / iPad Safari:** Open **Share** (the square with an upward arrow), choose **Add to Home Screen**, then tap **Add**. Keep **Open as Web App** enabled if shown.
- **In-app browsers:** Copy the game link and open it in Chrome or Safari, then follow the guide.

After installation, launch the game from its Band Duel icon. Playing and signing in require an internet connection.
